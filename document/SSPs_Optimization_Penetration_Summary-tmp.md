# SSP 场景优化渗透率分析总结

## 一、三个 SSP 场景的渗透率目标函数一致性

三个 SSP 场景的目标函数 `f(2) = sum(flexible_ele) / sum(loads)` 逐字节相同，都是最小化 f(2) 即最大化渗透率。三个场景的核心差异仅有两个参数：**年负荷总量**（TWh）和**基荷比例**（baseload_fraction）。

关于碳中和与 SSP 场景的矛盾：论文原意是碳中和（IEA NZE 路径），但三个 SSP 的基荷比例来自 AR6 模型的 business-as-usual 预测。SSP5-6.0（基荷 85.8%）确实与碳中和相悖；SSP2-4.5 理论上可在 2070 后实现碳中和，但 2050 年时基荷仍高达 71.3%。

## 二、互联拓扑

| 阶段 | 基线 (IEA NZE) | SSP1/2/5 |
|------|---------------|----------|
| 2050 | S-G（全球互联） | S-C（大陆互联） |
| 2040 | S-C | S-C |
| 2030 | S-A | S-A |

三个 SSP 与基线仅在 2050 年不同（S-G → S-C），2040 和 2030 完全一致。SSP5 用 S-C 是合理的。

### 3.3 关键发现

1. **2050/2040 年**：SSP2-4.5 和 SSP5-6.0 的最大可再生份额精确等于 AR6 风光占比（Gap = 0.0 pp）。因为总渗透率达到 100%，风光完美覆盖基荷以外的全部负荷，可再生份额 = `1 − baseload_fraction`，恰好等于 AR6 风光占比定义。
2. **SSP1-2.6 在 2050/2040 年**：最大可再生份额略低于 AR6（−1.5 / −1.4 pp），Pareto 前沿上没有解能完全消除 `flexible_ele`。
3. **所有场景的 2030 年差距最大**（−2.5 ~ −5.3 pp）。2030 使用 S-A 互联，输电能力受限，风光互补调度不充分，可再生份额低于 AR6 预测。S-A 互联是瓶颈。
4. **弃电率随基荷比例递增**：SSP5-6.0 的 2050 选中解弃电率高达 72.7%，而 SSP1-2.6 仅 31.5%。高基荷意味着风光只需覆盖小部分负荷，容易产生过剩弃电。

## 四、三个概念的定义

基于代码公式精确定义：

| 概念 | 公式 | 含义 |
|------|------|------|
| **渗透率** | `1 − f(2) = (sum(loads) − sum(flexible_ele)) / sum(loads)` | 系统总满足率（基荷 + 风光） |
| **风光渗透率** | `渗透率 − baseload_fraction` | 风光净消纳占比（扣弃电和储能损耗） |
| **风光占比** | `sum(grid_gens) / sum(loads)` | 风光毛发电量占比（含弃电） |

三者关系：

```
总负荷 (sum(loads)) = 100%
├── 基荷满足：    baseload_fraction            ← 煤/气/核/水等（固定扣除）
├── 风光净消纳：  风光渗透率                   ← 风光实际供给负荷的部分
└── 未满足：      f(2) = flexible_ele / loads  ← 需化石灵活电源补充

渗透率       = 基荷满足 + 风光净消纳
风光渗透率   = 渗透率 − baseload_fraction        （净消纳视角）
风光占比     = sum(grid_gens) / sum(loads)       （毛发电视角）

风光占比  ≥  风光渗透率    （因为占比含弃电，渗透率不含）
```

AR6 报告中的"风光占比"基于发电量数据（`Secondary Energy|Electricity` 变量，EJ/yr），非装机容量。计算公式：

```
AR6 风光占比 = (Solar发电量 + Wind发电量) / 总发电量
            = (Secondary Energy|Electricity|Solar + ...|Wind) / Secondary Energy|Electricity
```

AR6 同时提供装机容量（`Capacity|Electricity|Solar/Wind`，GW）和发电量（`Secondary Energy|Electricity|Solar/Wind`，EJ/yr）两类独立变量，风光占比使用的是发电量口径。
