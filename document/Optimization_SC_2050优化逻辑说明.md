# Optimization_SC_2050 优化逻辑说明

## 优化流程简介

这是一个 **NSGA-II 多目标优化**（`gamultiobj`），种群 1000，迭代 200 代，求解 2050 年 SSP1-2.6 情景下"大陆互联"模式的最优空间布局。

### 三个优化目标

1. **弃电率最小化** — 可再生发电中被浪费的比例
2. **灵活电源需求最小化**（= 最大化可再生渗透率）
3. **系统总成本最小化** — 光伏/风电/储能/输电的投资成本

### 决策变量结构

```
[光伏选址(0/1) | 风电选址(0/1) | 储能功率(20区域) | 储能时长(20区域) | 输电容量(各链路)]
```

选址变量决定哪些候选格网被选中，储能和输电是连续变量（被当作整数约束处理）。

### 调度逻辑（8760小时逐时模拟）

每小时对每个区域：

1. **先算供需差** = 风电+光伏发电 - (负荷 - 基荷)
2. **跨区输电** — 富余区向缺电区送电（DFS 找路径，最多 2 跳中继）
3. **储能充放电** — 富余时充电，缺电时放电
4. 如果仍有缺电 → 记为"灵活电源需求"；仍有富余 → 记为"弃电"

---

## 关于水电、核电、化石燃料

**它们不作为决策变量参与优化**，而是以**基荷（baseload）**的形式**预设扣除**。

具体做法见 `OptFun_SC_Dispatch_2050.m:30-33`：

```matlab
tmp = tmp - sum(tmp)*0.446/8760;  % 基荷占比44.6%，均匀分配至每小时
```

即：

- 假设 2050 年 SSP1-2.6 情景下，**水电 + 核电 + 化石燃料等非可再生/灵活电源提供 44.6% 的电力**
- 这 44.6% 被从负荷中**均匀扣除**（平铺到 8760 小时），当作恒定出力
- 优化器只需为**剩余 55.4% 的负荷**安排风光+储能+输电

模型**不区分**基荷中水电、核电、化石燃料各自占多少，也不区分它们出力的时序特性（如水电的丰枯季、核电的检修停机等），统一假设为**平稳出力**。

## 储能

储能**参与优化**，是决策变量的一部分：

| 参数 | 含义 | 范围 |
|------|------|------|
| 储能功率（20个区域） | 最大充/放电功率 | 下界=当前已有储能，上界=区域峰值负荷 |
| 储能时长（20个区域） | 满功率可持续时间 | 2h ~ 72h |
| 效率 | 充/放电各 95% | 固定参数 |

调度时储能按简单规则：富余→充电，缺电→放电，充至满或放至空为止。成本项为 **350 十亿美元/TWh**。

## 约束

非线性约束（`nonlcon2050.m`）只要求：每个区域选中的风光装机 ≥ 该区域当前已安装容量（不能拆已有电站）。
