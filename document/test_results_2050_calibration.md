## 3. 根因分析

### 3.1 核心问题：f(2) 渗透率目标主导优化行为

目标函数 f(2) 的计算逻辑（`OptFun_SC_Dispatch_2050.m`）：

```matlab
% 从总负荷中减去基荷（44.6%为平直基荷）
grid_load = loads - loads * 0.446 / 8760 * 8760;

% 调度逻辑：每小时用可再生发电覆盖 grid_load
% flexible_ele(t) = max(0, grid_load(t) - sum(gen_at_t))

% f(2) = sum(flexible_ele) / sum(loads)
% 注意：分母是原始 loads，不是 grid_load
```

**f(2) 的含义**：未被可再生发电覆盖的负荷占总负荷的比例。优化器将 f(2) 推向 0，
意味着要在**每一个小时**都用可再生发电覆盖全部非基荷负荷（55.4%的总负荷）。

**这导致**：
- 优化器需要建设大量可再生装机来覆盖"最差小时"（负荷高、风光出力低的时段）
- 总装机达到 ~30,000–35,000 GW，而 AR6 仅需 12,217 GW
- 混合容量因子仅 ~13.9%（AR6 约 28.2%），因为大量装机在低出力时段才被利用

### 3.2 solar_mult 为何无效

在三分量目标（弃电率、渗透率、成本）中：
- **f(2) 渗透率**远比 **f(3) 成本**重要——优化器优先满足 f(2)→0
- 即使光伏成本提高 4 倍，优化器仍大量选择光伏，因为：
  - 光伏候选格网数量远多于风电（光伏格网覆盖全球陆地，风电受限于风资源分布）
  - 在 NSGA-II 的 Pareto 前沿中，满足 f(2)→0 的解集中，成本差异被压缩
  - 光伏虽然单位成本提高了，但单位面积的可用装机容量大，选择灵活性高

### 3.3 cap_penalty 为何无效

容量惩罚以软惩罚形式加入 f(3)：
```matlab
f(3) = obj_cost + cap_penalty * max(0, total_cap_GW - 12217)
```

- 当 cap_penalty=50 时，额外惩罚约为 50 × (30000-12217) ≈ 889,150 $B
- 但原始成本 f(3) 本身就在数千到上万 $B 量级
- 更重要的是，减少装机意味着 f(2) 渗透率变差，这在 Pareto 排序中的惩罚远大于成本增加
- 优化器宁可选择"高装机+高成本"的解，也不愿牺牲渗透率

### 3.4 风电为何始终偏低

风电装机始终在 ~3,300–3,400 GW，即使光伏成本提高 4 倍：
- 风电候选格网经过严格筛选（容量 >0.0001 TWp，年发电 <10 TWh），数量较少
- 风电的容量因子虽然更高（~25-40%），但时间分布不如光伏多样
- 在满足逐小时渗透率约束时，光伏的"地理分散+时间互补"优势更大

## 4. 可能的解决方案

### 方案 A：硬约束限制总装机（推荐优先尝试）

在 `nonlcon2050.m` 中添加总装机上限约束：

```matlab
% 在现有 c(1), c(2) 之后添加：
MAX_TOTAL_GW = 14050;  % AR6 上限
total_cap_GW = sum(tmp_c) * 1000 + sum(tmp_c2) * 1000;  % 光伏+风电
c(3) = total_cap_GW - MAX_TOTAL_GW;  % ≤0 表示不超限
```

**优点**：直接限制总装机，不依赖目标函数权衡  
**缺点**：可能导致无可行解（如果硬约束与渗透率目标矛盾），需要测试可行性  
**风险**：gamultiobj 对非线性约束的处理可能不够精确，需要调整 ConstraintTolerance

### 方案 B：修改 f(2) 目标函数定义

将 f(2) 从"最小化未覆盖负荷比例"改为"最小化与目标渗透率的偏差"：

```matlab
TARGET_PENETRATION = 0.554;  % AR6 SSP1-2.6 可再生渗透率
actual_penetration = 1 - sum(flexible_ele) / sum(loads);
f(2) = abs(actual_penetration - TARGET_PENETRATION);
% 或者只惩罚超额渗透（允许不足）：
f(2) = max(0, actual_penetration - TARGET_PENETRATION);
```

**优点**：从根本上解决"过度建设"问题  
**缺点**：改变了优化问题结构，可能影响 Pareto 前沿形态  
**风险**：f(2) 不再是单调的，可能影响 NSGA-II 收敛

### 方案 C：直接约束可再生渗透率上限

保持 f(2) 不变，但通过负荷缩放或基荷比例间接控制：

```matlab
% 将基荷比例从 44.6% 提高到使总装机匹配 AR6 的水平
% 通过实验确定：如果总装机 = 30,000 GW 对应基荷 44.6%，
% 那么 12,217 GW 大约对应基荷 = 1 - (1-0.446) * 12217/30000 ≈ 77.4%
base_load_fraction = 0.774;  % 而不是 0.446
grid_load = loads - loads * base_load_fraction / 8760 * 8760;
```

**优点**：不改变优化结构，只调整参数  
**缺点**：基荷比例失去了物理意义（77.4% 基荷不符合 SSP1-2.6 情景）  
**风险**：可能引入与 AR6 其他指标不一致的问题

### 方案 D：约束风光比例 + 总装机

在 `nonlcon2050.m` 中同时添加总装机约束和风光比例约束：

```matlab
% 总装机上限
c(3) = total_cap_GW - 14050;

% 风电最低装机（至少占总装机的 47.5%）
wind_pct = wind_cap_GW / total_cap_GW;
c(4) = 0.475 - wind_pct;  % 风电占比 ≥ 47.5%
```

**优点**：同时控制总量和结构  
**缺点**：约束过多可能导致可行域极小或为空

### 方案 E：两阶段优化

1. **第一阶段**：用硬约束（方案 A）限制总装机 ≤14,050 GW，优化选址和调度
2. **第二阶段**：从第一阶段的 Pareto 前沿中选择最接近 AR6 比例的解

**优点**：分步求解，每步目标明确  
**缺点**：实现复杂度高

## 5. 建议的下一步

1. **优先尝试方案 A**（硬约束限制总装机）：
   - 修改 `nonlcon2050.m` 添加 `c(3) = total_cap_GW - 14050`
   - 设置 `MAX_TOTAL_GW = 14050`（AR6 + 15%）
   - 同时恢复 `solar_mult = 1.0`（先不加光伏成本惩罚）
   - 运行优化，观察是否能在总装机约束内得到可行解

2. **如果方案 A 可行但光伏占比仍偏高**：
   - 叠加方案 D，添加风电最低装机约束
   - 或结合适度的 solar_mult（1.5–2.0）

3. **如果方案 A 导致无可行解**：
   - 说明在硬约束的总装机上限下，无法满足逐小时渗透率要求
   - 此时需要采用方案 B，修改 f(2) 的定义
   - 或者放宽基荷比例，减少需要可再生覆盖的负荷量
