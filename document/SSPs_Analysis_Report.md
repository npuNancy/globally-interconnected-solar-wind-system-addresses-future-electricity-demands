代码当前的假设混合了两个来源：

|---------|---------|------|

## 四、区域电力需求来源分析

### 4.1 `Global_Load_22region.mat` 的生成方式

`Global_Load_22region.mat` 是一个**预生成的黑盒输入文件**，本代码库中**不存在生成脚本**。

**论文方法**（`论文.md` 第67-78行）描述了两步法：

1. **年总需求**：基于 SSP1-2.6 GDP/人口预测（IIASA SSP 数据库），用经验公式 `Ey = a·(e^(b·GDPy) − e^(c·GDPy))` 估算
2. **小时曲线形状**：基于 Toktarova et al. (2019) 的正弦叠加模型 `load(t) = Σᵢ (aᵢ · sin^ηᵢ(bᵢt + cᵢ) + dᵢ)`

论文最后将结果**线性校准**到 IEA NZE 年总量——即代码中的 `/71164` 操作。

### 4.2 负荷数据重缩放机制

```matlab
% Optimization_SG_2050.m 第78-81行
load Global_Load_22region.mat
all_loads = squeeze(all_loads(4,:,:))/1000/1000;   % ① 选择2050切片，GW→TW
global_load = sum(all_loads,1);                      % ② 20区域求和→1×8760
all_loads = all_loads / (sum(global_load(:))/71164); % ③ 缩放到目标TWh
```

**关键结论**：步骤③是一个**标量乘法**，等比例缩放到目标年总量。

| 保留/替换 | 来源 | 是否随情景改变 |
|----------|------|:-----------:|
| **小时时间形状**（日/季节周期） | Toktarova 正弦模型（.mat 文件内） | ❌ 保留 |
| **区域分布**（各区域占比） | SSP1-2.6 GDP/人口（.mat 文件内） | ❌ 保留 |
| **年总量**（TWh） | 硬编码常数 | ✅ 替换 |

### 4.3 结论：只需替换年总量，无需重新生成 .mat 文件

`.mat` 文件中的区域分布**已经是基于 SSP1-2.6 的 GDP/人口**生成的。替换年总量（71164→54767）即可完成 SSP1-2.6 适配。

### 4.4 关于使用 AR6 GDP 数据做区域分配

| 数据源 | 是否可用 | 说明 |
|--------|---------|------|
| AR6 `GDP\|PPP` | ❌ 仅全球汇总 | World 级别，无区域分解 |
| `data/GDP_data/GDP_PPP2015.mat` | ⚠️ 仅 2015 年基准 | 栅格化 GDP（~1km 分辨率），可用于区域聚合，但不含未来情景预测 |
| **`.mat` 文件已有分布** | ✅ 已内置 SSP1-2.6 | 无需额外 GDP 数据 |

**结论**：对于 SSP1-2.6，`.mat` 文件已包含正确的区域分布，**无需从 AR6 或 GDP 栅格数据重新分配**。

### 4.5 迁移到其他 SSP 时的区域分布问题

如果要迁移到 SSP2-4.5 或 SSP5-6.0：

- 不同 SSP 的 GDP/人口增长路径不同（如 SSP5-60 的亚洲增长更快）
- 理想的方案是**用对应 SSP 的 GDP/人口数据重新运行 Toktarova 正弦拟合**
- 但生成 `.mat` 文件的代码**不在本仓库中**
- **近似方案**：仍使用当前 `.mat` 的区域分布形状，仅替换年总量。误差取决于区域分布差异（通常较小，因为长期趋势下各 SSP 的区域格局相似）

## 五、Onshore/Offshore 风电拆分分析

### 5.1 代码中的处理方式

代码通过 `Global_LandMask.tif` 自动区分陆上/海上风电：

```
landmask==1 → 陆地 → Onshore → 装机密度 4.6 MW/km²
landmask==0 → 海洋 → Offshore → 装机密度 2.7 MW/km²
```

**成本区分**：
- `CGrid_Index(:,3)==0`（海洋）→ 按区域差异化成本（如亚洲 1,313 $/kW）
- `CGrid_Index(:,3)==1`（陆地）→ 统一高成本 3,461 $/kW

### 5.2 是否有 Onshore/Offshore 比例约束？

**没有。** 代码中：

- `nonlcon*.m` 的非线性约束仅检查**总风电装机** ≥ 现有装机（`cur_wind` 为各区域合计值，不区分 onshore/offshore）
- 优化器根据容量因子和成本自由选择 onshore/offshore 场站
- `Global_Init_State.mat` 中的 `cur_wind` 是 20×1 向量，每个区域一个合计值

**结论**：原代码**不需要也不使用** Onshore/Offshore 拆分比例。优化器通过经济优化自然决定 onshore/offshore 比例。无需添加额外约束。

### 5.3 AR6 数据中的 Onshore/Offshore 拆分

| 数据层级 | 是否提供拆分 |
|---------|-----------|
| World 级别 | ❌ 无（仅有 `Capacity\|Electricity\|Wind` 合计值） |
| R5 区域级别 | ❌ 无 |
| ISO3 国家级别 | ✅ 有 `Secondary Energy\|Electricity\|Wind\|Onshore` 和 `Offshore`，但仅1个模型(GCAM)、7个国家 |

**结论**：AR6 World 数据不提供 Onshore/Offshore 装机容量拆分。用户提供的 91%/9% 比例可作为参考，但由于代码中不需要此约束，**无需修改**。

## 九、关键发现与总结

### 1. 核心缺口已补齐

AR6 原始数据中**已包含**修改所需的两个关键参数：
- **总电力需求** (`Secondary Energy|Electricity`) — 直接替换年负荷总量
- **发电量技术分解** — 推算基荷比例

### 2. 三个 SSP 情景的核心差异

| 指标 (2050) | SSP1-26 | SSP2-45 | SSP5-60 | 当前代码 (IEA NZE) |
|------------|---------|---------|---------|-------------------|
| 总电力需求 | 54,767 TWh | 51,940 TWh | 65,277 TWh | 71,164 TWh |
| 基荷比例 | 23.9% | 51.8% | 64.2% | 9% |
| 风光占比 | 55.4% | 28.7% | 14.2% | 91% |
| Solar 装机 | 5,799 GW | 2,951 GW | 1,317 GW | 优化自由决定 |
| Wind 装机 | 6,418 GW | 3,232 GW | 2,143 GW | 优化自由决定 |

### 3. 区域分布无需修改

- `.mat` 文件中的区域分布已基于 SSP1-2.6 GDP/人口生成
- 替换年总量（标量乘法）自动等比缩放所有区域
- AR6 无区域级电力需求数据
- 迁移到其他 SSP 时，区域分布差异可通过近似处理

### 4. Onshore/Offshore 无需拆分

- 代码通过 landmask 自动区分，优化器自由决定比例
- AR6 World 数据不提供拆分
- 无约束需要修改

### 5. 迁移到其他 SSP 的操作步骤

以 SSP2-4.5 为例（修改 `Optimization_ssp245/`）：

```
步骤1: 复制 Optimization/ 到 Optimization_ssp245/
步骤2: 修改 2050 互联拓扑（如保持全球互联或大陆互联，视研究设计而定）
步骤3: 替换年负荷总量 → 见第七节 7.1
步骤4: 替换基荷比例 → 见第七节 7.2
步骤5: 按 2050→2040→2030 顺序运行优化
```

仅需修改 **6个硬编码值**（3个年总量 + 3个基荷比例），其他参数保持不变。
