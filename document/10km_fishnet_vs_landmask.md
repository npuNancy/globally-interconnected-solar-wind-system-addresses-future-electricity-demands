# Global_fishnet.tif 与 Global_LandMask.tif 数据结构说明

## 结论：不能直接用 land/sea mask (0/1) 生成 Global_fishnet.tif

---

## Global_fishnet.tif

| 属性 | 值 |
|---|---|
| 维度 | 180 × 360（1°×1° 全球网格） |
| 数据类型 | uint32 |
| 分辨率 | 1.0° × 1.0° |
| CRS | 无 |
| 边界 | [-180, -90, 180, 90] |
| NoData 值 | 65536 |
| 有效格网数 | 13296 |
| 有效值范围 | 1551 ~ 43191（ArcGIS 生成的唯一格网编号） |
| 有效格网纬度范围 | -55° ~ 60° |
| 有效格网经度范围 | -179° ~ 179° |

**值编码规则：**
- `< 65536`：有效陆地格网，值为 ArcGIS 分配的唯一编号（不连续，有 680 个间隔）
- `= 65536`：无效区域（海洋或面积不足的陆地格网，如南极、格陵兰内陆冰盖、小岛屿等）

**与 LandMask 的差异：**
- LandMask 标记为陆地的 15390 个格网中，有 2094 个被 fishnet 排除（主要是格陵兰、南极等偏远区域的 1° 格网）
- fishnet 标记为有效的 13296 个格网中，有 1732 个在 LandMask 中标记为海洋（沿海格网）

**本质：** 不是简单的 land/sea mask，而是 ArcGIS 经过面积阈值筛选后的陆地格网编号。

**在优化中的用途：**
```matlab
grids = geotiffread('Global_fishnet.tif');
solar_index = find(grids < 65536);  % 确定光伏候选场站
```

## Global_LandMask.tif

| 属性 | 值 |
|---|---|
| 维度 | 180 × 360（1°×1° 全球网格） |
| 数据类型 | uint8 |
| 分辨率 | 1.0° × 1.0° |
| CRS | EPSG:4326 |
| 边界 | [-180, -90, 180, 90] |
| NoData 值 | 255 |
| 唯一值数量 | 22 |

**值编码规则（两位数编码）：**

值的十位（first digit）代表大洲/区域：

| 十位 | 含义 | 像素数 |
|---|---|---|
| 0 | 特殊（仅 2 个像素） | 2 |
| 1 | 亚洲 | 3061 |
| 2 | 欧洲/格陵兰 | 4404 |
| 3 | 非洲 | 2560 |
| 4 | 大洋洲 | 772 |
| 5 | 美洲 | 4591 |

值的个位（second digit）代表地表类型：

| 个位 | 像素数 | 推测含义 |
|---|---|---|
| 0 | 2 | 特殊值 |
| 1 | 6391 | 主要陆地区域 |
| 2 | 1517 | 沿海/过渡带 |
| 3 | 1069 | 沿海/岛屿 |
| 4 | 5753 | 主要陆地区域 |
| 5 | 658 | 冰盖/特殊地貌 |

NoData 值 255：49410 个像素（海洋）。

**在优化中的用途：**
```matlab
landmask = readgeoraster('Global_LandMask.tif');
landmask(landmask < 100) = 0;   % 陆地
landmask(landmask > 100) = 1;   % 海洋
% 用于区分陆上风电（onshore, 密度 3.68 MW/km²）和海上风电（offshore, 密度 6.07 MW/km²）
```

## 两者关系总结

| 对比项 | Global_fishnet.tif | Global_LandMask.tif |
|---|---|---|
| 数据类型 | uint32 格网编号 | uint8 分类编码 |
| 有效像素数 | 13296 | 15390（陆地） |
| 功能 | 筛选光伏候选场站 | 区分陆上/海上风电装机密度 |
| 筛选粒度 | 排除了面积不足的陆地格网 | 包含所有陆地格网（含偏远岛屿） |
| 是否可互相替代 | 否 | 否 |
| 来源 | ArcGIS fishnet + 面积筛选 | ArcGIS 土地覆盖分类 |
