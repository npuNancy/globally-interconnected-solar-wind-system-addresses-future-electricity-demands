# SSP1-2.6 场站开发比例变量（连续容量）代码修改计划

## 1. 目标

在保留现有 SSP1-2.6 三阶段优化流程的基础上，将风光候选格网的决策变量由“整格建设或不建设”的二值变量改为“格网技术潜力开发比例”的连续变量。

现有逻辑为：

\[
x_i \in \{0, 1\}
\]

其中：

- \(x_i=0\)：不开发候选格网 \(i\)；
- \(x_i=1\)：按照该格网的最大技术潜力进行完整开发。

修改后的逻辑为：

\[
0 \le x_i \le 1
\]

其中：

- \(x_i=0\)：不开发；
- \(0<x_i<1\)：仅开发该格网技术潜力的一部分；
- \(x_i=1\)：完整开发该格网技术潜力。

格网实际装机容量为：

\[
C_i^{\text{actual}}=x_iC_i^{\max}
\]

格网逐小时实际出力为：

\[
G_{i,t}^{\text{actual}}=x_iG_{i,t}^{\max}
\]

本次只修改 SSP1-2.6，不改动 `Optimization_ssp126` 原目录，也不改动 `Optimization_ssp245` 和 `Optimization_ssp560`。

## 3. 当前代码中的二值逻辑位置

修改前，需要明确当前代码如何将格网限制为二值选址。

### 3.1 优化变量被设置为整数

在三个主优化脚本中，当前代码包含：

```matlab
lb=zeros(1,nvars);
ub=ones(1,nvars);

...

intcon=1:1:length(lb);
```

由于风光格网变量上下界为 `[0, 1]`，并且被加入 `intcon`，因此只能取 `0` 或 `1`。

### 3.2 调度函数再次执行取整

三个调度目标函数中均包含：

```matlab
CGrid_Index(:,2)=round(scale(1:length(CGrid_Index)));
```

这会把格网变量重新转换为二值状态。

### 3.3 发电量仅汇总完整选中的格网

三个调度目标函数中均使用：

```matlab
index=find((CGrid_Index(:,1)==gg_ind)&(CGrid_Index(:,2)==1));
selgens=gens(index,:);
grid_gens(gg_ind,:)=nansum(selgens,1);
```

即只有状态等于 `1` 的格网参与发电。

### 3.4 成本仅统计完整选中的格网

成本计算中使用：

```matlab
CGrid_Index(:,2)==1
```

筛选完整选中的格网，并直接累加其最大装机容量。

### 3.5 后处理再次执行取整

`convert_h5_to_sel.m` 中使用：

```matlab
solar_sel = round(scale(1:N_solar));
wind_sel  = round(scale(N_solar+1:N_grid));
```

然后将选中位置统一赋值为 `1`：

```matlab
opt_solar(solar_index(solar_sel == 1)) = 1;
opt_wind(win_index(wind_sel == 1)) = 1;
```

Python 后处理脚本中也使用了 `np.round()`。

## 4. 新的数据语义

修改后，建议统一使用以下术语。

| 名称 | 含义 |
|---|---|
| `site_frac` | 每个候选格网的开发比例，范围 `[0, 1]` |
| `ins_cap` | 每个候选格网的最大技术潜力容量 |
| `effective_ins` | 每个候选格网的实际建设容量，即 `ins_cap .* site_frac` |
| `gens` | 按照最大技术潜力预计算的逐小时发电序列 |
| `grid_gens` | 乘以 `site_frac` 后，聚合到 20 个区域的实际逐小时发电序列 |
| `opt_solar_frac` | 映射回全球栅格后的光伏开发比例 |
| `opt_wind_frac` | 映射回全球栅格后的风电开发比例 |
| `EPS_ACTIVE` | 判定格网是否有效开发的数值阈值，建议为 `1e-6` |

为了兼容已有接口，可以继续保存：

```matlab
opt_solar
opt_wind
```

但其语义改为“开发比例栅格”，不再是二值栅格。建议同时额外保存语义明确的别名：

```matlab
opt_solar_frac
opt_wind_frac
```

## 8. 新增统一的连续出力聚合函数

新增：

```text
Optimization_ssp126_test_continuous/aggregate_fractional_generation.m
```

建议实现：

```matlab
function [grid_gens, effective_ins, site_frac] = ...
    aggregate_fractional_generation(ins_cap, gens, region_id, site_frac, n_regions)
% aggregate_fractional_generation
% 按照格网开发比例缩放装机容量和逐小时出力，并聚合到区域。

site_frac = site_frac(:);
site_frac = max(0, min(1, site_frac));

ins_cap = ins_cap(:);
region_id = region_id(:);

assert(length(site_frac) == length(ins_cap), ...
    'site_frac 与 ins_cap 长度不一致');
assert(size(gens, 1) == length(ins_cap), ...
    'gens 行数与候选格网数量不一致');

effective_ins = ins_cap .* site_frac;

grid_gens = zeros(n_regions, size(gens, 2));

for region_idx = 1:n_regions
    index = (region_id == region_idx);
    grid_gens(region_idx, :) = ...
        sum(gens(index, :) .* site_frac(index), 1, 'omitnan');
end
end
```

### 为什么新增这个函数

三个目标函数都需要执行相同操作：

1. 将比例约束到 `[0, 1]`；
2. 计算实际装机容量；
3. 缩放逐小时出力；
4. 聚合到 20 个区域。

统一封装可以降低三个年份代码不一致的风险。

## 10.3 成本计算改为实际建设容量

当前成本计算通过：

```matlab
CGrid_Index(:,2)==1
```

筛选格网，并累加 `ins_cap`。

修改后：

- 不再使用 `CGrid_Index(:,2)==1`；
- 所有成本均基于 `effective_ins`；
- `effective_ins = ins_cap .* site_frac`。

建议先定义：

```matlab
load NonlConData.mat nonlsol

n_grid = length(ins_cap);
is_solar = ((1:n_grid).' <= nonlsol);
is_wind = ~is_solar;

is_offshore = is_wind & (CGrid_Index(:, 3) == 1);
is_onshore = is_wind & (CGrid_Index(:, 3) == 0);
```

海上风电：

```matlab
obj_cost = obj_cost + 3461 * sum(effective_ins(is_offshore));
```

亚洲：

```matlab
is_region = (CGrid_Index(:,1) > 8) & (CGrid_Index(:,1) < 14);

obj_cost = obj_cost ...
    + 927.6 * sum(effective_ins(is_solar & is_region)) ...
    + 1313  * sum(effective_ins(is_onshore & is_region));
```

其他区域同理。

### 为什么必须同步修改成本

如果只缩放发电量，不缩放成本，就会出现：

- 开发 10% 的容量；
- 但支付 100% 的建设成本。

因此，发电与成本必须使用同一组比例变量。

## 14. 统一重构非线性约束

当前三个非线性约束函数返回“不满足约束的区域数量”。例如：

```matlab
tmp_e=tmp_solar<cur_solar;
c(1)=sum(tmp_e);
```

这种写法存在两个问题：

1. 无法区分缺少 1 MW 和缺少 100 GW；
2. 原有 `ConstraintTolerance=4` 或 `8` 的单位是“区域数量”，不能继续用于容量缺口。

建议新增统一约束函数：

```text
Optimization_ssp126_test_continuous/continuous_capacity_constraints.m
```

建议内容：

```matlab
function [c, ceq] = continuous_capacity_constraints(x, data_file)
% continuous_capacity_constraints
% 保证各区域未来光伏和风电实际装机不低于已有装机。
%
% MATLAB 非线性约束要求 c <= 0。

load(data_file, ...
    'nonlcon_sel', ...
    'nonlcon_ins', ...
    'nonlcon_ub', ...
    'nonlsol', ...
    'nonlwin');

load Global_Init_State cur_solar cur_wind

cur_solar = cur_solar / 1e6;  % MW -> TW
cur_wind  = cur_wind  / 1e6;

site_frac = x(1:(nonlsol + nonlwin));
site_frac = site_frac(:);

solar_frac = site_frac(1:nonlsol);
wind_frac = site_frac(nonlsol+1:nonlsol+nonlwin);

solar_ins = nonlcon_ins(1:nonlsol);
wind_ins = nonlcon_ins(nonlsol+1:nonlsol+nonlwin);

solar_region_id = nonlcon_sel(1:nonlsol, 1);
wind_region_id = nonlcon_sel(nonlsol+1:nonlsol+nonlwin, 1);

solar_region = accumarray( ...
    solar_region_id, ...
    solar_frac .* solar_ins, ...

    0 ...
);

    wind_frac .* wind_ins, ...
```

## 14.1 约束可行性检查

在正式优化前，应检查每个区域的最大可用容量是否足以覆盖已有装机。

最大可用容量为：

\[
C_{r}^{\max,\text{available}}
=
\sum_{i \in r}
C_i^{\max}\cdot ub_i
\]

建议在三个主优化脚本中输出诊断信息：

```matlab
solar_max = accumarray( ...
    CGrid_Index(1:nonlsol, 1), ...
    all_ins(1:nonlsol) .* nonlcon_ub(1:nonlsol), ...
    [20, 1], ...
    @sum, ...
    0 ...
);

wind_max = accumarray( ...
    CGrid_Index(nonlsol+1:end, 1), ...
    all_ins(nonlsol+1:end) .* nonlcon_ub(nonlsol+1:end), ...
    [20, 1], ...
    @sum, ...
    0 ...
);
```

如存在无法覆盖已有容量的区域，默认应停止运行并打印区域编号，而不是继续使用模糊的容差绕过：

```matlab
if any(solar_max + 1e-12 < cur_solar) || any(wind_max + 1e-12 < cur_wind)
    error('存在无法覆盖已有装机容量的区域，请检查候选格网或父阶段比例上限');
end
```

如果后续确实需要放宽约束，应单独增加明确的配置参数，并把放宽区域和容量缺口写入日志，不要继续使用“允许违反若干个区域”的隐式逻辑。

## 24. 风险与注意事项

### 24.1 连续变量不保证最终一定出现大量部分开发格网

虽然模型允许：

\[
0<x_i<1
\]

但由于目标函数结构、区域资源差异和 Pareto 解选择方式，某些最优解仍可能包含大量接近 `0` 或 `1` 的值。

因此：

- “允许连续容量”是模型能力；
- “最终一定出现大量部分开发格网”不是验收条件。

### 24.2 NSGA-II 搜索空间会发生变化

二值选址改为连续比例后：

- 搜索空间更加平滑；
- 候选解表达能力增强；
- 收敛特征可能变化；
- 正式运行前必须先做小规模 smoke test；
- 正式结果建议比较多个随机种子。

### 24.3 父阶段比例必须作为子阶段上限

只将：

```matlab
==1
```

改成：

```matlab
>0
```

是不够的。

如果 2050 年某格网只开发 40%，2040 年仍然必须满足：

\[
x_{2040} \le 0.4
\]

不能重新把上限恢复成 100%。

### 24.4 数值噪声必须统一处理

遗传算法可能产生极小正数，例如：

```text
1e-12
```

建议统一使用：

```matlab
EPS_ACTIVE = 1e-6
```

用于：

- 有效格网筛选；
- 输出清理；
- 跨年份候选格网筛选；
- CSV 导出。

### 24.5 约束容差不能沿用原来的含义

原始 `ConstraintTolerance=4` 和 `ConstraintTolerance=8` 对应的是“允许若干区域违反条件”。

重构后约束变为容量缺口，容差应改为较小的数值误差阈值，例如：

```matlab
1e-8
```

如果某些区域无法覆盖已有容量，应显式报错并记录，而不是依靠较大的容差跳过。
