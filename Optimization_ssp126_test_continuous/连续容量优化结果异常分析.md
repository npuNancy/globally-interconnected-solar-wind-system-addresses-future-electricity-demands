# 连续容量优化结果异常分析

## 问题描述

连续容量（开发比例）版本的优化结果存在两个异常现象：

1. **格网数跨年份几乎一致**：2030/2040/2050 三年的有效开发格网数基本相同（光伏 ~5700，风电 ~6800），没有逐年递增的区分度。
2. **光伏装机容量远高于二值版本**：连续版 2050 年光伏装机 27,921 GW，是二值版 6,275 GW 的 4.5 倍。

## 结论：不是 pop/gen 参数问题

pop=1000、gen=200 的 2050 结果与 pop=30、gen=3 的冒烟测试呈现**完全相同的模式**——选择几乎所有可用候选格网，平均开发比例约 0.5。这说明问题不在于优化参数不足，而是连续变量公式本身的结构性缺陷。

## 根本原因：连续变量缺乏稀疏性约束

### 二值优化的隐式稀疏压力

在二值（0/1）优化中，每个格网的决策变量只能取 0 或 1：

- 选择一个格网 = 贡献 **100% 容量** + 承担 **100% 成本**
- 不选择 = 0 容量 + 0 成本
- 每个格网有明确的**门槛成本**，优化器被迫只选最优的少数格网

二值 SSP1-2.6 2050 结果：光伏 2,448 格网（覆盖率 26.7%），风电 3,442 格网（覆盖率 40.6%）。

### 连续优化的"稀疏压力消失"

在连续（0~1 开发比例）优化中，每个格网的决策变量可在 [0, 1] 范围内任意取值：

- 选一个格网 fraction=0.01 → 仅承担 1% 成本，但获得**地理多样性收益**
- 激活一个新格网的边际成本趋近于零
- **没有任何惩罚机制阻止优化器激活更多格网**

优化器的理性策略变为："在所有可用格网上都开发一点，以获得最平滑的发电曲线"。

连续 SSP1-2.6 2050 结果：光伏 5,716 格网（覆盖率 62.4%），风电 6,880 格网（覆盖率 81.2%），平均开发比例 0.49。

### 对比数据

| 指标 | 二值 2050 | 连续 2050 | 比值 |
|------|-----------|-----------|------|
| 光伏有效格网数 | 2,448 | 5,716 | 2.33× |
| 风电有效格网数 | 3,442 | 6,880 | 2.00× |
| 光伏装机容量 (GW) | 6,275 | 27,921 | **4.45×** |
| 风电装机容量 (GW) | 4,613 | 4,222 | 0.92× |
| 总装机容量 (GW) | 10,888 | 32,143 | 2.95× |
| 弃电率 | 0.4237 | 0.4040 | — |
| 可再生渗透率 | 0.9927 | 0.9801 | — |
| 系统成本 (十亿$) | 85,066 | 75,083 | — |

**关键发现**：目标函数值（弃电率、渗透率、成本）相近，但装机容量相差 4.5 倍。连续版通过大量"铺开"式开发实现了平滑发电曲线，代价是总装机容量远超实际需要。

### 为什么光伏受影响远大于风电

| 资源类型 | 总技术潜力 (GW) | 连续版装机 (GW) | 占技术潜力比例 |
|----------|-----------------|-----------------|----------------|
| 光伏 | 62,926 | 27,921 | 44.3% |
| 风电 | 9,007 | 4,222 | 46.9% |

光伏和风电的开发比例（占技术潜力）其实相近（~45%），但光伏的**绝对技术潜力远大于风电**（63,000 GW vs 9,000 GW），因此相同比例下光伏装机膨胀更严重。

## 2040 年优化未充分收敛

pop=1000、gen=200 的 2040 结果仅产生 **1 个 Pareto 解**（正常应有数百个），说明：

- 2050 的连续开发比例作为 2040 的上限约束，搜索空间过大（每个格网的上限为 0~0.98 而非固定的 1.0）
- 12,538 个连续格网变量 + 40 个储能 + 74 个输电 = 12,652 维搜索空间，gamultiobj 难以有效探索

## 可能的修复方向

### 方案 A：固定场站开发成本（推荐）

在目标函数 f(3) 成本项中，为每个 fraction > 0 的格网增加固定成本（代表电网接入、场地平整、变电站等不随容量线性变化的基建费用）：

```
obj_cost = obj_cost + C_fixed × sum(site_frac > eps)
```

这模拟了现实中的规模经济：建设一个大场站比建设许多小场站更经济。

### 方案 B：最小开发比例约束

将格网变量的下限从 0 改为一个最小阈值（如 0.1 或 0.2），低于此值的格网自动设为 0：

```matlab
lb = zeros(N_grid, 1);
ub = ones(N_grid, 1);
% 优化后后处理：
scale(scale < min_frac) = 0;
```

或在 `gamultiobj` 中直接设：

```matlab
lb(lb == 0) = min_frac;  % 但这会强制所有格网都开发
```

需配合最大格网数约束使用。

### 方案 C：L1 正则化

在成本目标中加入 L1 惩罚项，鼓励稀疏解：

```
obj_cost = obj_cost + lambda × sum(site_frac)
```

其中 `lambda` 为正则化系数，需调参。

### 方案 D：最大格网数约束

在非线性约束中限制活跃格网总数不超过某阈值：

```matlab
function [c, ceq] = nonlcon(x, ...)
    c(1) = sum(x(1:N_grid) > eps) - max_grids;  % 不等式约束
    ceq = [];
end
```

## 总结

| 问题 | 原因 | 是否与 pop/gen 有关 |
|------|------|---------------------|
| 格网数跨年一致 | 连续变量无激活成本，优化器选择所有格网 | 否 |
| 光伏装机远高于二值 | 技术潜力基数大 × 覆盖率高 × 中等比例 | 否 |
| 2040 未收敛 | 搜索空间过大 + 连续变量维度高 | 部分相关 |

核心问题是连续变量公式丢失了二值变量的隐式 L0 稀疏性，需要在目标函数或约束中显式引入稀疏性压力。
