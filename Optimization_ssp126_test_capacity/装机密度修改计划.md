# 修改单位面积装机容量 — 实施计划

## 背景

对比两篇论文代码后发现，当前项目的装机密度（光伏 74、陆上风电 2.7、海上风电 4.6 MW/km²）与第一篇论文（Paris Agreement）的参数差异显著。需要以 `Optimization_ssp126/` 为基础，创建 `Optimization_ssp126_test_capacity/`，采用第一篇论文的参数方案进行修改。

## 参数变更

| 类型 | 旧值 | 新值 | 性质 |
|---|---:|---:|---|
| 光伏 | 74 MW/km² | 161.9 × Ω(lat) × 0.15 MW/km² | 纬度依赖 |
| 陆上风电 | 2.7 MW/km² | **3.68** MW/km² | 常数 |
| 海上风电 | 4.6 MW/km² | **6.07** MW/km² | 常数 |

光伏密度公式中：
- **161.9** W/m² = 光伏组件标准功率密度（STC 条件）
- **Ω** = 地面覆盖率比 GCR = cos(β) / (cos(β) + sin(β)/tan(α_min))，其中 β 为面板倾角，α_min 为冬至正午太阳高度角
- **β** = 0.35396 × |lat| + sign(lat) × 16.84775°（与现有 CF 模拟脚本一致的倾角公式）
- **α_min** = 90° − |lat| − 23.45°
- **FR** = 0.15（统一值。LUCC 面积数据已编码土地覆盖约束，空间分异 FR 会导致双重计算）

预期密度范围：赤道 ≈ 21.4 MW/km² → 高纬度（60°）≈ 3.1 MW/km²

## 步骤 2：新建 `compute_pv_density.m`

**文件**：`Optimization_ssp126_test_capacity/compute_pv_density.m`

输入：180×360 矩阵的线性索引向量（如 `solar_index = find(grids < 65536)`）
输出：每个格网的 PV 装机密度（MW/km²），列向量

核心逻辑：
```matlab
function pv_density = compute_pv_density(solar_index)
    FR = 0.15;
    rows = mod(solar_index - 1, 180) + 1;   % 180×360 矩阵的行号
    lat  = 90.5 - rows;                      % 纬度

    beta      = 0.35396 * abs(lat) + sign(lat) * 16.84775;  % 倾角
    alpha_min = 90 - abs(lat) - 23.45;                      % 冬至高度角
    alpha_min = max(alpha_min, 0.1);                        % 极夜保护

    beta_rad     = deg2rad(beta);
    alpha_min_rad = deg2rad(alpha_min);

    Omega = cos(beta_rad) ./ (cos(beta_rad) + sin(beta_rad) ./ tan(alpha_min_rad));
    pv_density = 161.9 * Omega * FR;
    pv_density = pv_density(:);
end
```

设计说明：
- FR 取统一 0.15：LUCC 面积 TIF 已包含土地覆盖筛选，空间分异 FR 会双重计算
- α_min 下界 0.1°：防止高纬度极夜时 tan(0) 除零
- sign(lat) 处理：赤道格网 lat=0.5（非精确零），无问题

## 风险与注意事项

1. **光伏容量大幅下降**：新密度（3~21 MW/km²）远低于旧值 74，总装机潜力将显著缩减。这可能导致优化需要选中更多格网才能满足同样的需求
2. **筛选阈值**：`solar_ins > 0.001 TWp` 的阈值在新密度下更难达到，高纬度小面积格网可能被排除
3. **优化收敛**：密度变化改变决策变量的重要性分布，可能需要调整种群规模或迭代次数
4. **不需要额外数据**：所有计算基于现有 TIF 文件的纬度信息，不引入外部数据
