- Optimization_SG_2050.m: 2050年全球互联情景（S-G）的空间布局优化主程序
    - OptFun_SG_Dispatch_2050.m: 2050年全球互联情景的多目标调度函数
    - nonlcon2050.m: 非线性约束


## 一、输入数据

代码共需要以下输入文件，分为四类。

### 1. 风电相关空间数据

**`Global_Wind_Net_Area_Add_Egrid.tif`**, 数据形状: (180, 360)
每个500m像元中可用于风机安装的净面积占该像元总面积的百分比（0–100%），即Table S3三重筛选（可开发性+可达性+可互联性）后的结果栅格。除以100后得到小数形式的适宜性系数。

**`Global_Wind_Fishnet_Area.tif`**, 数据形状: (180, 360)
每个500m像元的实际地理面积（km²），用于将"面积比例"转换为"可用绝对面积"。

**`Global_LandMask.tif`**, 数据形状: (180, 360)
区分陆地（值≥100）和海洋（值<100）的二值掩膜，用于区分陆上风电（安装密度2.7 MW/km²）和海上风电（安装密度4.6 MW/km²），进而计算每个格网的最大装机容量（单位：TWp）。

**`Global_Wind_CFs_Sel.h5`（数据集 `/data`**, 数据形状: (8760, 8477)
筛选后保留的8477个风电候选格网，每个格网在2000–2022年均气候条件下的8760小时容量因子（CF）序列。由ERA5再分析数据的100m风速代入风机功率曲线并考虑尾流损耗计算得到（对应论文方法公式6）。

### 2. 光伏相关空间数据

**`Global_fishnet.tif`**, 数据形状: (180, 360)
全球1°×1°格网编号图，用于标识哪些格网存在有效的光伏候选位置（值<65536表示有效格网）。

**`Global_Solar_CFs`（MAT文件，变量 `res_CF`**, 数据形状: (13296, 8760)
13296个光伏候选格网的8760小时容量因子矩阵，由ERA5的地表太阳辐照、气温数据代入PVLIB模型（公式1–5）计算得到，除以10000（代码中 `/10/1000`）转换为无量纲小数形式。

**`Global_Solar_Net_Area_Add_Egrid.tif`**, 数据形状: (180, 360)
光伏候选格网内可安装光伏板的净面积占比（%），同样来自三重适宜性筛选结果。

**`Global_Solar_Fishnet_Area.tif`**, 数据形状: (180, 360)
光伏候选格网的实际地理面积（km²）。代码中以74 W/m²的平均安装密度将面积转换为最大装机容量，单位为TWp（`74 × area_km² / 1e6`）。

### 3. 电力负荷数据

**`Global_Load_22region.mat`（变量 `all_loads`）**, 数据形状: (9, 20, 8760)
20个区域在不同发展阶段的逐小时电力需求（原始单位为GW，除以1e6后转为TW）。代码取第4个切片（索引4对应2050年代），并将全球总负荷归一化至71,164 TWh/年（即IEA NZE情景下2050年全球总用电量）。这是论文方法中用正弦函数叠加模型拟合得到的未来负荷曲线，驱动因子来自IIASA SSP1-2.6数据库中的GDP和人口预测。

### 4. 系统状态与互联结构数据

**`Global_Grid_Division.tif`**, 数据形状: (180, 360)
每个500m像元所属的区域编号（1–20），对应联合国地理方案划分的20个区域电网。用于将候选格网归属到对应的区域。

**`Global_Init_State.mat`（变量 `cur_storage`、`cur_trans`、`cur_solar`、`cur_wind`）**, 数据形状: (20, 1)
现有装机的初始状态：`cur_solar`和`cur_wind`为2020年各区域已有的光伏和风电装机（GW，来源为IRENA 2024可再生能源统计报告），作为非线性约束的下界（新方案每个区域的装机不得低于现有水平）；`cur_storage`为现有储能装机（GW），作为储能功率下界；`cur_trans`为现有跨区输电容量（GW），作为输电功率下界。

**`Global_Trans.mat`（变量 `trans_connections`、`trans_loss`）**, 数据形状: (20, 20)
20×20的区域间连接矩阵（邻接矩阵，S-G全球互联拓扑）和对应的输电损耗矩阵（%/1000km，结合HVDC陆上5%/1000km、海上3%/1000km的假设）。

## 二、整体代码流程

流程分为数据准备、变量构造、优化求解三个阶段。

### 阶段一：候选格网筛选与发电量预计算（`Optimization_SG_2050.m` 前半段）

首先对风电格网做两轮筛选：第一轮剔除装机容量过小的格网（`wind_ins ≤ 0.0001 TWp`，记录为`wind_ind1`），第二轮剔除年发电量过低的格网（`sum(wind_gen) ≥ 10 TWh`者保留，被剔除的记录为`wind_ind2`，最终保留的记录为`wind_ind3`）。光伏同理（两个阈值分别为0.001 TWp和90 TWh年发电量）。

最终进入优化的候选格网数：光伏约13000+个（`solar_index`），风电约8000+个（`win_index`）。将两类候选格网的发电量矩阵和装机容量向量垂直拼接，得到 `all_gens`（维度约21773×8760，单位TWh/h）和 `all_ins`（约21773×1，单位TWp）。

将每个候选格网归属的区域编号存入 `CGrid_Index` 第一列，第二列留给优化变量（是否选中），第三列标记陆上/海上（0/1）。

### 阶段二：优化变量定义与边界设置

决策变量向量 `scale` 的结构如下：

- 前 `nvars` 位（约21773维）：0或1的二值整数，表示每个候选格网是否被选中
- 第 `nvars+1` 到 `nvars+20` 位：各区域储能系统额定功率（GW），下界为现有装机，上界为该区域峰值负荷的1000倍
- 第 `nvars+21` 到 `nvars+40` 位：各区域储能时长（小时），范围2–72小时
- 第 `nvars+41` 到末尾：各条跨区输电走廊的最大输电功率（GW），下界为现有容量，上界为10,000 GW

`intcon=1:length(lb)` 将所有变量设为整数约束（场站选择为0/1整数，储能和输电容量被四舍五入为整数GW，这是计算效率与精度的折中处理）。

### 阶段三：`nonlcon2050.m`——非线性约束

该函数只施加一条约束，且以**计数不等式**的形式表达：对20个区域分别汇总当前解中光伏和风电的选中装机容量，若某区域汇总值小于其现有装机（`cur_solar`或`cur_wind`），则对应的惩罚计数加1。两个约束变量 `c(1)`、`c(2)` 分别统计有多少区域的光伏/风电装机不达标。`gamultiobj` 要求 `c ≤ 0` 才算可行解，因此只有所有区域均满足"新装机 ≥ 现有装机"时，该解才被视为可行。

### 阶段四：`OptFun_SG_Dispatch_2050.m`——目标函数

这是计算量最大的核心部分，对每个候选解执行完整的全年8760小时跨区调度模拟：

**步骤1**：根据 `scale` 前段的0/1选择，汇总每个区域的小时发电量曲线 `grid_gens`（20×8760）。

**步骤2**：从每个区域的负荷中扣除9%作为基荷贡献（IEA NZE情景假设），得到需风光满足的净负荷 `grid_load`。

**步骤3**：在每个时间步，按以下优先级顺序调度：①有盈余区域通过最短损耗路径向有缺口区域输电（`findAllPathsFromStart`寻找所有可达路径并按损耗排序，依次传输直到路径容量或盈余耗尽）；②剩余盈余存入储能，超出储能容量的弃电；③储能放电弥补剩余缺口，不足的部分计入 `flexible_ele`（需灵活调峰电源补充）。

**步骤4**：计算三个目标函数值并返回：
```
f(1) = sum(curtailed_ele) / sum(grid_gens)   % 弃电率（最小化）
f(2) = sum(flexible_ele) / sum(loads)        % 1-渗透率（最小化）
f(3) = 总初始投资（十亿美元）               % 成本（最小化）
```
成本按光伏/风电按洲际分区的单位造价（USD/kW）、输电容量（98亿美元/TW）和储能容量（350亿美元/TWh）加总。

### 阶段五：`gamultiobj` 求解与结果存储

`gamultiobj`使用遗传算法求解上述三目标整数规划问题，默认种群大小和迭代次数运行完成后，将帕累托解集 `res_scale`（每行为一个可行解的决策变量向量）和帕累托前沿 `prs`（每行为对应解的三个目标函数值）写入HDF5文件。
